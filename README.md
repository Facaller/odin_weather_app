# ⛅ Minecraft Weather App

**Live Demo:** [View on GitHub Pages](https://facaller.github.io/odin_weather_app/)

A simple, themed weather application that fetches real-time data from the Virtual Crossing API. The UI is Minecraft-themed for a fun and niche twist. This project was a shorter build, focused on clean functionality and async programming practices.

## 🌦️ Features

- Search for current weather by city name
- Fetches data from the Virtual Crossing API
- Toggle between Metric and Imperial units
- Dynamically updates the UI with weather conditions
- Minecraft-inspired design

## 🎯 Purpose

This app was built to practice asynchronous JavaScript, API interaction, and user interface updates. After building a large-scale app (my todo app), I intentionally kept this project simple and focused on fundamentals.

## 🛠️ Built With

- HTML
- CSS
- JavaScript (ES6+)
- Virtual Crossing API

## 🧠 Lessons Learned

- Fetching and handling external API data
- Error handling for user input and API failures
- State management across different units (Metric/Imperial)
- UX/UI consistency in a themed application

## 📦 Setup

1. Clone the repo
2. Add your Virtual Crossing API key in the designated place in the code
3. Open `index.html` in your browser
